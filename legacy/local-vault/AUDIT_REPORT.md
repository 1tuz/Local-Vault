# Аудит и исправление Local Vault Starter

Дата: 2026-10-12. Среда: macOS ARM64. Цель — собрать запускаемое локальное приложение без Python-сервера и восстановить исходный интерфейс проекта.

## Что было не так

1. Ранее вместо сохранения готового HTML/CSS интерфейса был сделан отдельный экран-заготовка на `eframe`. Он потерял исходную навигацию и функции UI.
2. В текущем Tauri-варианте HTML запрашивал стили и скрипт из `/static/`, хотя Tauri размещает файлы frontendDist в корне. В WebView показывался неоформленный HTML без логики.
3. Документация описывала Python-сервер и агентские функции как текущую архитектуру, а старый отчёт утверждал, что macOS app не собирался. Это перестало соответствовать приложению.

## Исправления

- Восстановлено использование исходного UI проекта: категории, поиск, карточки записей, глаз, копирование скрытого значения, история и откат.
- Исправлены пути CSS/JS для Tauri WebView. Отдельное окно приложения работает без Python и без localhost-сервера.
- Сохранена оригинальная иконка DopaBase; собран ARM64 `.app` в `/Users/antony/Desktop/Local Vault.app`, применена и проверена локальная ad-hoc подпись.
- Удалён переключатель доступа AI-агента: backend Rust пока не предоставляет такого интерфейса, и показывать неработающее разрешение было бы обманчиво.
- Python-сервер, пакет, старые Python-тесты и виртуальное окружение удалены из проекта. Реализованный Rust backend содержит vault CRUD, версии, откат и YAML/JSON импорт/экспорт.
- Обновлены README, архитектурная схема, модель безопасности и отчёт тестов.

## Результаты проверок

- Rust тесты: **3 пройдено, 0 упало, 0 пропущено**.
- Clippy: успешно, `-D warnings`.
- ARM64 release build: успешно.
- `.app` packaging, ad-hoc codesign и codesign verify: успешно.
- Реальный запуск `.app` и visual CUA: успешно; после исправления виден оформленный исходный экран создания хранилища.
- `cargo audit`: 0 vulnerabilities. Остались 2 advisory warnings: unmaintained `proc-macro-error` в build graph и `glib` advisory, отсутствующий в macOS ARM64 target graph.
- После проверки удалён Cargo `target` (4.9 GiB allocated; доступное место на томе выросло примерно на 4.76 GiB). Установленный `.app` сохранён и проверен.

## Реализованные сценарии

Unit-тесты подтверждают шифрование/отказ с неверным паролем, запись и редактирование, историю, возврат содержимого выбранной версии, импорт/экспорт и отказ на некорректном формате. GUI подтверждён только на стартовом экране. GUI-ввод мастер-пароля, создание базы через окно, полный CRUD-цикл, копирование и системный file picker в этом прогоне не подтверждены.

## Не реализовано или не проверено

- CLI/MCP для Codex, OpenCode и Pi, безопасный SSH signing и HTTPS агентский посредник не перенесены в Rust.
- Настройки SSH/API сохраняются как metadata; выполнение SSH/HTTPS запросов отсутствует.
- Поддержка kubectl не реализована.
- Не проверена совместимость с существующей базой или миграция. Сначала сделайте резервную копию.
- Не выполнялся независимый аудит безопасности; same-user malware, дампы памяти и очистка буфера обмена по таймеру не покрыты.
- App ad-hoc подписан, но не подписан Developer ID и не нотариализован.

Приложение можно запускать для дальнейшего тестирования на синтетических данных. Без агентских функций, теста восстановления существующей базы и независимого аудита его нельзя считать готовым к производственным секретам.
