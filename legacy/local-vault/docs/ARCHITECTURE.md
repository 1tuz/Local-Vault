# Архитектура текущего macOS-приложения

```text
Локальные HTML/CSS/JS-файлы в Tauri WebView
                   │ invoke IPC
                   ▼
         Rust команды приложения
                   │
       rusqlite SQLite in-memory
                   │ serialize → AES-GCM
                   ▼
           локальный .vault-файл
```

Внешний веб-сервер, Python-процесс и localhost-порт не используются. UI вызывает Rust-команды через Tauri IPC. Вызовы ограничены зарегистрированными командами `api_request` и `export_file`.

## Хранилище

Контейнер: `LVLT0001 || salt(16) || nonce(12) || AES-GCM(ciphertext + tag)`. Argon2id v1.3 использует 64 MiB, 3 прохода, parallelism 2 и 32-байтовый ключ. AAD — magic и salt. Перед расшифровкой проверяются размер и magic; после SQLite-десериализации выполняется `integrity_check`.

SQLite открыта только в памяти. Сохранение сериализует базу, шифрует новым nonce и атомарно заменяет файл. Файл ограничен 32 MiB, запись — 1 MiB, импорт — 4 MiB. Каталог и файл создаются с правами 0700 и 0600. Используются lock-файл, проверка на symlink и fsync.

## Записи и версии

Поддерживаются `secret`, `ssh`, `kubeconfig`, `api`, `env`, `file`; история хранит снимок записи и содержимое. Откат добавляет новую версию из выбранной старой. Поиск выполняется по названию и папке.

UI содержит кнопки-глаз и копирования. Значение можно скопировать, пока поле визуально скрыто. Буфер обмена управляется WebKit/macOS, приложение не очищает его автоматически.

## Границы реализации

MCP, CLI, SSH agent signing и посредник HTTPS отсутствуют в текущей Rust-сборке. AI-агентам приложение не предоставляет интерфейс. Наличие SSH/API metadata в записи не означает выполнение подключения или запроса.

Файл базы, экспорт и резервные копии требуют защиты владельцем. После разблокировки содержимое находится в памяти процесса и UI WebView. Локальный процесс с тем же пользователем ОС может взаимодействовать с процессом или извлекать данные из пользовательской сессии. Это прототип, не прошедший независимый аудит.
